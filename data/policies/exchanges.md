# Exchanges Policy

Owner: Store Operations

## When an exchange is allowed
An item can be exchanged whenever it would be eligible for a return under the Returns and Refunds policy (same windows, same conditions). Final Sale items cannot be exchanged, except for a size exchange on apparel within 14 days.

## Same item, different size or color
Swap directly at the register. No restocking fee applies, even for opened electronics, as long as the exchange is for the **same model**.

## Different item
Process as a return plus a new purchase. If the new item costs more, the customer pays the difference. If it costs less, the difference is refunded to the original payment method. Restocking fees apply to the returned item as usual.

## Out-of-stock replacements
If the replacement is out of stock in store, the employee can place a ship-to-home order at no shipping cost. Do not hold the returned item; process the return the same day.

## Online orders
Online orders can be exchanged in any store. The employee needs the order number (format NM-XXXXX) or the card used for the purchase.
